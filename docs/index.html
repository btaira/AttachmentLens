Run it yourself

git clone https://github.com/btaira/AttachmentLens.git
cd AttachmentLens
docker-compose up

Visit http://localhost:5000. Default login: admin / admin. Requires Docker Desktop.

pip install -r requirements.txt

Requires Python 3.8+. Visit http://localhost:5000 after startup.

Deploy to the cloud

Host a live instance on Render (free tier) so you can access it from anywhere.

  1. Fork the AttachmentLens repository to your GitHub account.
  2. Create a new Web Service on render.com and connect your fork.
  3. Set the runtime to Docker — Render will detect the Dockerfile automatically.
  4. Add a Disk (under Advanced) mounted at /app/data — this persists your SQLite database across deploys.
  5. Deploy. Visit your Render URL, log in with admin / admin, and change the password.
